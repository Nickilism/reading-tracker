# 全部年份总览页设计（All-Years Overview）

## 目标

- 新增一个「全部年份」总览页 `reading archive/all.html`，把 2019 年至今（当前年份）的所有阅读记录呈现在同一页面。
- 首页 `index.html` 的顶部统计条（年数 / 本数 / 页数）整体变为入口，点击进入总览页。
- 页面沿用年度页 `template.js` 的设计语言与组件，做以下改造：
  1. 保留顶部搜索栏、统计条、国家分布；
  2. 每月阅读量柱状图 → 每年阅读量柱状图 + 累计阅读量趋势线（合并一张图）；
  3. 月份筛选 → 年份筛选；
  4. 保留书影留存、书籍清单；
  5. 保留每本书的笔记 / 划线面板（懒加载）；
  6. 新增「高分榜 Top 10」（位置 P1：图表区之后、筛选条之前；样式 S1：横排封面卡 + 名次角标）。
- **年份范围不得写死**：起点为常量 `START_YEAR = 2019`，终点为「当前年份」（动态计算）。2027、2028 等新年度页出现后，总览页自动纳入，无需改代码。

## 目录与文件约定

| 文件 | 角色 | 修改约定 |
| --- | --- | --- |
| `reading archive/all.html`（新增） | 全部年份总览页（静态外壳 + 运行时汇总逻辑），与年度页同目录 | 手工维护，不进入生成链路；样式与交互和 `template.js` / `index.html` 保持同构 |
| `index.html` | 归档首页 | 顶部统计条改为指向总览页的可点击入口 |
| `AGENTS.md` | 项目约定 | 目录表补 `all.html` 行；补「视觉同步」提醒 |

- `all.html` 与年度页同处 `reading archive/`：favicon / Chart.js 引用 `../icons/...`、`../vendor/chart.umd.js`（与年度页一致）；抓取年度页用同级相对路径 `./${year}_reading_tracker.html`。
- 首页入口链接：`reading%20archive/all.html`（与现有年度卡链接的编码方式一致）。
- 不修改 `template.js`、两个生成器、`builder_offline.js`、8 个年度页、`.github/workflows/deploy.yml`。
- 不要求全离线：`all.html` 运行时抓取年度页，`file://` 会因浏览器跨域限制失败；本地预览沿用 `preview.cmd`（HTTP）。

## 数据流

```text
index.html（顶部统计条 → reading%20archive/all.html）
  → all.html 打开时按 2019..当前年份 逐年 fetch：
      ./${year}_reading_tracker.html
  → 从每个年度页解析 const books = […]（字符串感知的平衡括号扫描）
  → 解析失败或 404 的年份：跳过并继续，不白屏
  → 合并为 allBooks[]，每本书补 year 字段（来自所在年度页）
  → 统计 / 国家分布 / 年图+累计线 / 年份筛选 / 高分榜 / 书影 / 清单
  → 点开某本书时，才从该书所在年度页的 HTML 懒解析 wereadData，渲染划线面板（每年度解析一次并缓存）
```

### 各年度页内嵌数据格式（已核对）

- 每个年度页都含且仅含一处 `const books = [` 与一处 `const wereadData = {`。
- `wereadData` 为对象：`{ <wereadId>: { rating, ratingCount, chapters, highlights, thoughts, popularHighlights } }`。
- 每本书对象含：`title / author / start / finish / rating / pages / doubanLink / cover / review / summary / id / report / month / country / wereadId`（`wereadId` 可缺省）。
- `cover` 为相对路径 `../covers/<hash>.<ext>`；`report` 为 `''` 或相对路径 `reports/<年份>/<recId>.html`；二者相对「年度页所在目录」解析（与 `all.html` 同目录，可直接用同一基准解析）。

## 页面结构（从上到下）

1. **标题区**：`阅读记录 · 全部年份`；副标题动态显示 `2019 – <当前年> · <N> 年`；右上角年份徽章显示 `ALL`（或跨度文字）。
2. **搜索栏**：跨全部年份搜索书名/作者；支持 `?search=` 深链（与年度页一致）。
3. **统计条**：已读书目 / 总页数 / 阅读天数中位数（与年度页三项一致，计算逻辑照搬）。
4. **国家分布**：跨年汇总，徽章随筛选联动。
5. **图表区**：Chart.js 一张图 = 每年阅读量柱状图 + 累计阅读量折线（右侧第二坐标轴），X 轴为年份升序；柱可点击筛选该年；色值通过读取 CSS 变量（`getComputedStyle`）获得，深浅色自适应；随搜索/筛选联动（柱 = 当前范围内每年本数，线 = 当前范围内逐年累计）。
6. **高分榜 Top 10**：图表区之后、筛选条之前。横排封面卡 + 名次角标（第 1–3 名用强调色，其余中性色，颜色走 CSS 变量）；标题 `高分榜 · Top 10`；只统计有评分（数字）的书；并列按完成日期新→旧；**随当前范围（搜索/筛选）联动**，不足 10 本时按实际数量展示。
7. **筛选条**：`全部` / 高分（≥8.4）/ 中评（>7.9 且 <8.4）/ 低分（≤7.9）/ 有报告 + 国家 + **年份**（动态生成，从当前年降序到 2019，带范围计数）；选中某一年时在旁提供「打开 {年} 年度页 ↗」小链接（同级 `./{year}_reading_tracker.html`）。
8. **书影留存**：当前范围内全部书籍封面，hover 补年份小标签。
9. **书籍清单**：可折叠；行内含年份标签；排序：时间 ↓ / 评分 ↓ / 页数 ↓ / 年份 ↓；有 `report` 的书渲染「阅读报告」按钮（相对路径基于 `reading archive/` 解析，无需额外前缀）；有 `wereadId` 的书显示划线指示（与年度页对齐）。
10. **笔记 / 划线面板**：点开某本书时懒加载 weread（见数据流），渲染结构对齐年度页面板；无 `wereadId` 或无数据时自然不显示划线区块。
11. **页脚**：`← 返回归档首页`（`../index.html`）+ 导出信息（「实时汇总 · 数据来自各年度页」）。

## 交互与联动规则

- 搜索、筛选任一变化 → 统计 / 国家 / 图表 / 高分榜 / 书影 / 清单全部重算（与年度页行为一致）。
- 深链：支持 `?search=`、`?year=`（可选 `?sort=`），打开即应用。
- 加载：逐年并行 fetch，渲染骨架屏；某年失败时跳过，页面底部提示「<年份> 暂未加载」，不阻塞其它年份。
- 无结果：沿用年度页 `no-results` 文案与样式。

## 视觉与一致性

- CSS 变量、字体、`.page` 780px、深浅色、移动端底部面板等，从 `index.html` / `template.js` 复制同源定义到 `all.html`（自包含页面，与现有页面一致）。
- 新增颜色（高分榜名次角标等）一律走 CSS 变量，禁止硬编码 hex/rgba。
- 新增文件行 + 同步提醒写入 `AGENTS.md`：今后改首页/年度页视觉或交互时，需同步 `all.html`。

## 边界与错误处理

- `fetch` 需要 HTTP；`file://` 失败时页面显示指引（用 `preview.cmd` 预览）。
- 某年度页 404 / 解析失败：跳过该年并提示，不中断。
- 年份范围：`START_YEAR = 2019`（常量，归档起始年）；终点 `new Date().getFullYear()`；两端之间逐年尝试，缺失年自动跳过。
- 解析 `books` / `wereadData` 使用字符串感知的平衡扫描（跳过引号内括号），比首页现有朴素扫描更稳；`wereadData` 只按需解析并缓存。
- 无划线数据、无 `wereadId`、无评分、无报告的边界均自然降级，不报错。
- 单文件全离线（`builder_offline.js` 流程）不在本次范围。

- 用生成器方式校验 `all.html` 内嵌脚本语法（提取 `<script>` 后 `node --check`，参照 `template.js` 校验惯例）。
- `preview.cmd` 起本地 HTTP 服务，浏览器自动化覆盖：
  - 首页统计条入口 hover / 键盘可达 / 点击跳转；
  - 总览页完整加载：统计数、国家、年图+累计线、高分榜、筛选、书影、清单、面板；
  - 跨年搜索、单年筛选（图表/统计/高分榜/书影/清单联动）、排序、`?search=`/`?year=` 深链；
  - 点开 ≥3 本不同年份的书验证划线懒加载与「阅读报告」按钮链接；
  - 窄屏、深色模式、无结果、某年度页缺失（临时模拟）不白屏。
- `git status` 核对变更范围：仅新增 `reading archive/all.html`、修改 `index.html` 与 `AGENTS.md`（含 README 可选）。
